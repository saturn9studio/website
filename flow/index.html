It's all about inspiration

Flow was built from the ground up as a modern, carefully designed experience, meant to inspire at every step.

Distraction-free writing

Focus mode provides an immersive, full screen writing experience. Everything except the current sentence is muted, so you can focus on what comes next.

Themes

Flow was designed to inspire. Explore multiple themes and pick the one that speaks to you.

Markdown formatting

Markdown allows you to quickly style your text, using the keyboard, without breaking stride. The markup disappears when not under cursor to remove distractions.

Every supported style is listed in the Markdown reference.

Flow CLI brings the same writing-first Markdown experience to the command line. Write in your terminal.
